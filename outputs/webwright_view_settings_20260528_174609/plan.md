# Critical Points
- [ ] CP1: The SentinelTwin Studio app loads successfully at the clean local server and the main shell is visible.
- [ ] CP2: The View Settings modal opens from the top bar entrypoint.
- [ ] CP3: The View Settings modal opens from the floating viewport controls entrypoint.
- [ ] CP4: The viewport controls switch the canvas between 3D and 2D and the reset control is available.
- [ ] CP5: Scene layer controls are visible in View Settings and at least one layer toggle changes state.
- [ ] CP6: A workspace preset or view mode change from View Settings visibly affects the workspace shell.
